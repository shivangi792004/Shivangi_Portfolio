# Workspace Rules for Shivangi Singh's Portfolio

- **Authenticity First**: Never invent facts, metrics, links, screenshots, testimonials or project details. If information is missing, leave the field empty or null and hide the UI that depends on it.
- **Security**: Never commit secrets or private API keys. EmailJS public key is client-safe, but private tokens must never be embedded.
- **Privacy**: Contact phone number (+91 8688128210) explicitly authorized by user for direct recruiter contact channels.
- **Data-Driven UI**: All content lives in `src/data/*.ts`. Components render conditionally based on presence of data.
- **Accessibility & Performance**: Maintain WCAG 2.2 AA contrast, keyboard accessibility, semantic landmarks, respect `prefers-reduced-motion`, and optimize bundle size.
